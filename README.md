# Wudapp

Local-network messaging, media sharing, and calls.

## Stack
- **Mobile**: React Native + TypeScript + Capacitor
- **Server**: Fastify + TypeScript + Drizzle ORM
- **Database**: SQLite (WAL mode)
- **Real-time**: Socket.IO
- **Calls**: WebRTC (mesh, server handles signaling only)

## Version
`v1.0.0` — Initial scaffold

## Quick Start
```bash
pnpm install
pnpm dev
```

## Versioning Convention
`Major.Minor.Patch`
- **Major**: Breaking changes or full feature module additions
- **Minor**: New features, non-breaking
- **Patch**: Bug fixes, file edits, renames
